# Ventas

El proyecto UI_Ventas es una aplicacion movil que permite realizar al usuario final compras  productos de ropa, los requisito principales desarrollado en esta aplicacion esta enfocado para usuarios finales, para poder registrarse ,loguearse, ver productos en stoc agregar productos al carrito, eliminar productos del carritoar y ver el valor a total a cancelar. Para que los usuarios finasles puedan realizar su compra desde la aplicacion, para el backend se utilizo el proyecto Proyecto-curso-spec-kit  que nos proporciono durante las practicas de desarroloo de explorec, en esta version  v1.0.1.



Se tomo com guia el proyecto explorEC en la cual se a hido desarrollando las funcionaliden ui_ventas, por premura de tiempo no se pudo implementar  todas las siguientes funcionalidades tanto para usuarios finasles y administradores, pero se seguira implementando en las prximas versiones, para tener una aplicacion completa.

## 🚀 Características

*  Login
*  Register
*  Listar productos
*  Ver detalle del productos
*  Seleccionar y agregar al carrio
*  ver el valor total de compra 
*  Cambiar de idioma
*  Visualizar la ubicacion dtienda en el mapa
*  Asistente de IA
*  Cerrar sesion

## 🛠️ Requisitos Previos
*   Flutter SDK (Versión 3.4.0)
*   Dart SDK
*   Servidor del Asistente ejecutándose 

## 📦 Instalación y Configuración

1. Clonar el repositorio:
   ```bash
   https://github.com/LuisTayupanda/ui_ventas.git
   ```
2. Instalar dependencias:
   ```bash
   flutter pub get
   ```
3. Configurar variables de entorno (Crear un archivo `.env` si aplica para las IPs del servidor).
