El proyecto UI_Ventas es una aplicacion movil que permite gestionar  productos y ventas de ropa, los requisito principales desarrollado en esta aplicacion esta enfocado para usuarios finales y vendedores, para poder registrar ,actualizar, eliminar y gestionar productos y ventas. Para que los usuarios finasles puedan realizar su compra desde la aplicacion, para el backend se utilizo el proyecto Proyecto-curso-spec-kit  que nos proporciono durante las practicas de desarroloo de explorec, en esta version  v1.0.0 se tiene las siguientes funcionalidades:

-Login
-Register
-Crear productos
-Actualizar productos
-Eliminar productos
-Listar productos
-Cerrar sesion
Por la premura de tiempo no se pudo implementar  todas las siguientes funcionalidades tanto para usuarios finasles y vendedores, pero se seguira implementando en las prximas versiones, para tener una aplicacion completa.
